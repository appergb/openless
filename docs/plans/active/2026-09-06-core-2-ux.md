## 验收与回滚

主页服务入口能打开对应设置；录音/快捷键/外观/服务/隐私/高级/关于均可达；移动端没有丢失录音或语言设置；查找与空结果可恢复；设置支持关闭和焦点返回。Linux 每个旧操作保留真实调用，导航不停止事件消费或丢弃会话。

使用 `npm test`（含构建）、必要的定向行为测试；Linux 源文件格式检查、Host/Core 测试及能执行的目标检查；浏览器检查常规桌面、短窗口与窄屏。当前主机是 macOS，Linux 原生桌面效果须明确留给 Linux 设备验收，不能以 macOS 上 cfg 排除的构建冒充。

改动均保持在此分支，按文件撤销可回到 `fc38edd1`；已删除的用户未提交修改不作可恢复承诺。风险集中在设置入口迁移、短窗口溢出、平台 gating 和 Linux 隐藏页面的会话状态。
